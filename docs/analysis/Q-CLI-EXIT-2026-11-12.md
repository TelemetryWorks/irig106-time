## Accepted mapping and planned verification

Trace: **L1-CLI-007 → L2-CLI-107 → L3-CLI-107**. L1 adds the fifth class,
output-write failure, to its previously four-class wording. The following
are planned tests for the CLI restructure step, not tests executed here.

| Code | Time classification | Planned test |
|---|---|---|
| 0 | Success | Valid input and successfully written output, no findings meeting the threshold. |
| 1 | Findings at or above the chosen severity | Exact-threshold finding returns 1; vary threshold to confirm the classification changes. |
| 2 | Usage error | Hand-rolled parser (ADR-0008) rejects unknown options and missing arguments; usage is checked before opening a nonexistent input. |
| 3 | Input could not be read or is not valid Chapter 10/time input | Unreadable input and malformed/non-time input both return 3. |
| 4 | Output could not be written | Inject a failing output writer; ensure failed or incomplete output does not become 0 or 1. |

Never renumber these assignments. The shared runner returns a classification
without terminating the host; only `main` maps it to process exit. Input and
output failures remain distinct from threshold findings. Existing usage-before-
input validation is retained; this decision does not invent an additional
priority between simultaneous input and output failures.

Code and tests belong to the **CLI restructure step**, carrying
`/// Requirements: L1-CLI-007, L2-CLI-107, L3-CLI-107` and correct code `Traces`
tags, so the regenerated matrix links requirement → code → test. This PR
changes only documentation; current CLI behaviour is not asserted to satisfy
the accepted mapping. Q-FLAGS code work remains a separate PR after this
documentation PR merges.

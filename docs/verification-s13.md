## ENC-103 recommendation before building any new capability

Keep a NEW complete secondary-header/stamp/checksum writer deferred past 0.8.0,
as owner Q3 already states. Existing public writer corrections remain blockers.
This crate currently exposes an eight-byte `encode_ieee_time` word encoder; it has
no full 12-byte secondary-header/stamp dispatcher accepting flags/checksum.
Audit/test existing word writers separately; do not silently add a new header
API or mark ENC-103 covered. A future full API should use explicit flags/layout,
reject undefined secondary-derived time, keep RTC padding/reserved words zero
and use the byte-sum reading without repairing invalid flags into valid time.
This is a recommendation, not authorization to implement that future API.

## S13a — complete ENC-102 wire contract

Sources: 106-24R1 §11.2.3.3a/b, Figures 11-15..17, printed 11-27/PDF 35; §11.2.1f
little-endian words. Official [Chapter11](https://www.trmc.osd.mil/wiki/download/attachments/335389015/chapter11.pdf?api=v2).
Golden bytes are literal arithmetic, not generated by a decoder or a roundtrip.
No new archive/rendered-page audit is claimed. Figure 11-15's reserved bits31..8,
NTF7..4 and TS3..0 give the six defined bytes 00/01/10/11/20/21. Figure 11-16
writes seconds 0x01020304 then fraction 0x89abcdef =>04 03 02 01 EF CD AB 89.
Figure 11-17 writes seconds then 500000000ns=0x1dcd6500 =>04 03 02 01 00 65 CD 1D.
Max 999999999ns=0x3b9ac9ff; both seconds fields are 32 bits. Individual vectors
cite their figure/section in tests/s13a_format2_encode.rs.

Existing wrong CSDW emission is corrected: checked output clears reserved
positions, refuses reserved NTF/TS selectors and never turns TS0 into TS1.
The original diagnostic word remains immutable/as_raw. PTP encoding revalidates
public raw structs; typed TaiSeconds construction rejects >u32::MAX before
narrowing. NTP raw fields already enforce 32-bit width; its infallible writer
preserves the full fraction and zero sentinel. These operations do not perform
NTP-era/UTC/TAI conversion, choose an edition/channel or write packet flags.

Tests-first commit `5c91645`: the existing reserved-word regression fails at runtime on
main (reserved bit8 leaks), while the independent body golden passes. Commit `3e8ab88`
adds checked API/overflow tests before implementation: arrays lack unwrap and
the typed constructor is missing, so these are compile-first, not additional
runtime-first claims. Final three tests include a whole-contract aggregate
calling the canonical-position/body goldens, all 256 NTF/TS pairs, TS0, every
reserved position, fraction extrema/zero, raw-state PTP errors and checked
seconds bounds. That aggregate covers L1-ENC-002 -> L2-ENC-102 -> L3-ENC-102.

Nine individually applied mutations killed by runtime assertions, source
restored each time: omit NTF guard; omit TS guard; preserve reserved bits;
force TS valid; accept nanos1e9; bypass raw-struct validation; truncate seconds;
zero NTP fraction; swap PTP words. No compile errors counted as mutation kills.
Focused local checks only: three encoder tests, nine existing slice2 wire tests,
and the PTP roundtrip property, plus fmt. Full matrix is GitHub CI, not rerun
locally (owner compute policy 2026-11-18). Caller migration is limited to the
existing PTP roundtrip property and slice2 writer assertion; CLI has no use.
